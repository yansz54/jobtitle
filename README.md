## The title

**Snake Milker, First Class**

## How it works

`node main.ts` writes the title to `/output/entry.txt`. Pure Node stdlib:
no network, no randomness, no clock. Two runs write byte-identical output.

See [METHOD.md](METHOD.md) for how the title was chosen (30 candidates,
single-elimination tournament against the published judge criteria).
